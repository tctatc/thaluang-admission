# ระบบรับสมัครเรียนออนไลน์ วิทยาลัยเทคนิคท่าหลวงซิเมนต์ไทยอนุสรณ์

ผู้สมัครกรอกใบสมัครบนเว็บ ระบบเติมข้อมูลลงใบสมัครโควตาที่วางตามตำแหน่งในกระดาษต้นฉบับ (`web/public/ใบสมัครโควตา-ต้นฉบับ.pdf`) แล้วพิมพ์หรือบันทึกเป็น PDF ได้ทันที เจ้าหน้าที่ตรวจเอกสาร เปลี่ยนสถานะ บันทึกการมอบตัว ออกรหัสนักศึกษา ดูแดชบอร์ด และส่งออก Excel/CSV ได้จากหน้าเดียวกัน

## ส่วนประกอบ

| โฟลเดอร์ | หน้าที่ |
|---|---|
| `shared/` | กฎของระบบ: ตรวจข้อมูล (เลขบัตร 13 หลักพร้อม check digit, เบอร์ 10 หลัก), ออกเลขใบสมัคร/รหัสนักศึกษา, สถิติ, ส่งออก มี test ครอบ |
| `apps-script/` | หลังบ้านบน Google Apps Script เก็บข้อมูลใน Google Sheets และไฟล์แนบใน Google Drive (`Domain.gs` สร้างจาก `shared/` ห้ามแก้มือ) |
| `web/` | หน้าเว็บ React ขึ้น GitHub Pages ได้ ถ้ายังไม่ตั้ง `VITE_API_URL` จะเข้าโหมดสาธิต (เก็บข้อมูลในเบราว์เซอร์) |

## ลองใช้ในเครื่อง (โหมดสาธิต)

```bash
cd web
npm install
npm run dev        # เปิด http://localhost:5174
```

หน้าเจ้าหน้าที่อยู่ที่ `#/staff` บัญชีสาธิต `admin / admin1234` และ `staff / staff1234` หน้าภาพรวมมีปุ่มเติมผู้สมัครตัวอย่าง 36 คนไว้ทดลองแดชบอร์ด

## ติดตั้งของจริง

> เอาขึ้น GitHub / แก้โค้ดแล้วอัปเดตเว็บ: ดู [docs/เผยแพร่ขึ้น-GitHub.md](docs/เผยแพร่ขึ้น-GitHub.md)

1. **สร้างโปรเจกต์ Apps Script** ที่ script.google.com ด้วยบัญชีของวิทยาลัย แล้วคัดลอกทุกไฟล์ใน `apps-script/` ไปวาง (ชื่อไฟล์ตามเดิม) และเปิด "Show appsscript.json" ใน Project Settings แล้ววางทับด้วยไฟล์ของเรา
2. **รัน `setupSystem`** หนึ่งครั้ง ระบบจะสร้างไฟล์ Google Sheets, โฟลเดอร์เก็บเอกสาร, กุญแจลับ และบัญชี `admin` จากนั้นเปิด Execution log เพื่อดูรหัสผ่านชั่วคราวของ admin และลิงก์ชีต
3. **แก้รายชื่อสาขา** ในชีต `Programs` (ตอนนี้เป็นรายการตัวอย่าง) รหัสสาขา 2 หลักจะใช้ประกอบรหัสนักศึกษา
4. **Deploy** > New deployment > Web app ตั้ง Execute as: **Me** และ Who has access: **Anyone** แล้วคัดลอก URL ที่ลงท้าย `/exec`
5. **ต่อหน้าเว็บ**: สร้าง `web/.env` ใส่ `VITE_API_URL=<URL /exec>` แล้วรัน `npm run build` นำโฟลเดอร์ `web/dist` ขึ้น GitHub Pages
6. **เพิ่มเจ้าหน้าที่**: แก้ค่าในฟังก์ชัน `addStaff` แล้วกด Run รหัสผ่านชั่วคราวขึ้นใน log (ลืมรหัสผ่านใช้ `resetStaffPassword`)

แก้โค้ดใน `shared/` แล้วต้องรัน `npm run build:domain` ที่โฟลเดอร์หลัก และคัดลอก `apps-script/Domain.gs` ไปวางใหม่ทุกครั้ง

### แจ้งเตือน (ไม่บังคับ)

LINE Notify ปิดบริการแล้วตั้งแต่ 31 มี.ค. 2025 ระบบนี้จึงใช้บอทของ LINE Official Account แทน ให้ใส่ค่าใน Project Settings > Script Properties:

| ค่า | ใช้ทำอะไร |
|---|---|
| `LINE_CHANNEL_TOKEN` | Channel access token ของ Messaging API |
| `LINE_TO` | groupId ของกลุ่มเจ้าหน้าที่ที่เชิญบอทเข้าไปแล้ว |
| `NOTIFY_EMAIL` | อีเมลเจ้าหน้าที่ที่จะรับแจ้งผู้สมัครใหม่ |
| `PUBLIC_SITE_URL` | ลิงก์หน้าเว็บ ใช้แนบในอีเมลถึงผู้สมัคร |

ทดสอบด้วยฟังก์ชัน `testLineNotify` ผู้สมัครที่กรอกอีเมลจะได้อีเมลเมื่อส่งใบสมัคร เมื่อเปลี่ยนสถานะ และเมื่อถูกขอให้ส่งเอกสารใหม่ ข้อความ LINE มีแค่เลขที่ใบสมัคร สาขา และโรงเรียน ไม่มีเลขบัตรหรือที่อยู่

## ความปลอดภัยที่ควรรู้

- ผู้สมัครเปิดใบสมัครได้ด้วย**เลขบัตร + วันเกิด** คู่กันเท่านั้น ค้นผิด 5 ครั้งต่อเลขบัตรจะถูกพัก 30 นาที และทั้งระบบมีเพดานความผิดพลาดรายชั่วโมง
- ไฟล์แนบใน Drive เป็นส่วนตัว เจ้าหน้าที่เปิดดูผ่านระบบหลังเข้าสู่ระบบ ระบบตรวจชนิดไฟล์จากเนื้อไฟล์จริง (JPG/PNG/PDF ไม่เกิน 5 MB)
- เอกสารที่ตรวจผ่านแล้วผู้สมัครเปลี่ยนไฟล์ไม่ได้
- ไฟล์ CSV กันสูตรแฝง (ค่าที่ขึ้นต้นด้วย `=` `+` `-` `@`) ส่วน Excel เก็บทุกช่องเป็นข้อความ เลข 0 หน้าเบอร์โทรจึงไม่หาย
- ข้อจำกัด: URL ของ Apps Script เป็นสาธารณะ ยังไม่มี CAPTCHA กันการส่งใบสมัครปลอมจำนวนมาก ถ้าพบปัญหานี้ให้ปิดรับชั่วคราวที่หน้าตั้งค่า

## ยังรอข้อมูลจากวิทยาลัย

- รายชื่อสาขาและรหัสสาขาจริง (ตอนนี้เป็นตัวอย่าง)
- แบบฟอร์มใบมอบตัวต้นฉบับ: ตอนนี้ใช้แบบทั่วไปชั่วคราว (`web/src/sheets/EnrollmentSheet.tsx`) ได้ต้นฉบับมาแล้วจะทำใหม่แบบวัดตำแหน่งเหมือนใบสมัคร
- ไฟล์แม่แบบนำเข้า ศธ.02 ของงานทะเบียน: ปรับลำดับคอลัมน์ได้ที่รายการ `REGISTRY` ใน `shared/exportData.ts`
- รูปแบบรหัสนักศึกษาจริง: ตั้งได้ที่หน้าตั้งค่า (ค่าเริ่มต้น `{YY}{L}{PP}{NNN}` เช่น 70201001)
